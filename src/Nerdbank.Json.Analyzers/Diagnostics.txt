NBJson001 (Usage, Warning): A generated or directly reflected serialization
contract contains unsupported delegate values. Explicit converters and known
marshaler surrogate contracts are respected. Unknown runtime configuration is
not inferred.

NBJson002 (Usage, Warning): A serialized dictionary key cannot be represented as
a JSON property name by the library's key formatter. Custom converters on the
dictionary can change the representation; converters on the key alone cannot.

NBJson020 (Usage, Error): A JsonConverterAttribute must name a non-abstract
JsonConverter<T> for the annotated type, field, property or parameter. An open
generic converter is closed using the annotated type's generic arguments.
For example, a converter for string cannot be assigned to an int property.
Use a matching converter or remove the attribute.

NBJson021 (Usage, Error): Attributed converters are activated at runtime and need
a public parameterless constructor. Private constructors and constructors with
optional parameters do not qualify. Supply a parameterless constructor or
register a configured converter instance on the serializer instead.

NBJson030 (Usage, Warning): A converter must not construct or call JsonSerializer.
Doing so starts a new serialization operation, losing the parent context's
depth limits and reference tracking. Obtain a nested converter through the
SerializationContext and call that converter with the existing reader/writer
and context. Calls outside converters are not diagnosed.

NBJson032 (Usage, Info): A concrete converter should override GetJsonSchema.
An inherited implementation also satisfies this rule. Without a schema override,
the schema generator cannot describe the converter's wire representation.
Implement an accurate schema; a permissive schema may be appropriate for a
converter that intentionally accepts any JSON value. Abstract converters and
unrelated methods named GetJsonSchema are not implementations of this contract.

NBJson031 (Usage, Warning): A synchronous converter has a provably incorrect
single-value structure on a normal return path. Unknown helpers, raw writes,
exception regions and repeated loop iterations stop inference. No automatic fix
is offered because a converter's representation cannot be guessed.

Generated code is excluded. Standard #pragma warning directives and .editorconfig
severity settings can suppress these rules where the design is intentional.

NBJson110 (Usage, Warning): A serializable primitive or enum member initialized in
source should declare System.ComponentModel.DefaultValueAttribute. For example,
use [DefaultValue(42)] on a property initialized to 42 so default-value omission
and schema generation know that value. The rule follows PolyType-generated shape
roots, witness attributes, wildcard witnesses and reachable nested types. Ignored
and unsupported members are excluded. Customized shape roots are not inferred.
The code fix adds a fully qualified [DefaultValue(...)] for constant initializers
and preserves primitive conversions. It deliberately does not fix computed
initializers or shared multi-variable fields, since either could change behavior.

NBJson050 (Usage, Warning): Pass JsonReader and JsonWriter parameters by ref to
preserve changes to their mutable state. Explicit in/ref/out parameters are not
diagnosed, nor are unrelated types or the asynchronous reader/writer classes.

NBJson051 (Usage, Warning): Prefer statically resolved shape mapping APIs when
the target runtime supports static virtual interface members. Framework and
Standard targets and explicit shape/provider overloads remain usable. Existing
hard-obsolete APIs remain compiler errors without a duplicate analyzer warning.
